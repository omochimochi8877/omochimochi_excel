# Free Children's Animation Automation MVP

This folder builds a simple 5-minute children's animation with GitHub Actions and FFmpeg only.

## Run
1. Open GitHub Actions.
2. Select `Create Children's Animation (Free MVP)`.
3. Click `Run workflow`.
4. When it finishes, download the `children-animation-mp4` artifact.

Story: The Little Star — a small round cloud creature discovers a glowing star, follows it, meets two friends, and returns home together.

This is the free foundation. Later, AI-generated images, narration, music, and short AI-video clips can be inserted into the same assembly pipeline.
